# pages

临时页面托管仓库，通过 GitHub Pages 发布。

- 线上地址：https://adamzhuang.github.io/pages/
- 用途：放一些不敏感的 HTML，临时分享给别人看
- 更新：改完 `git add . && git commit -m "..." && git push`，Pages 自动重新部署（约 1 分钟）

## 目录

- `index.html` — 站点首页
- `demo.html` — 快速页面生成器 Demo
- `finance-reporter/` — 宏观分析师「观潮」的每日日报归档，见该目录 README

## 注意

仓库是公开的，**不要放**任何密钥、token、内网地址、个人隐私信息。
