删除会话「产品经理」？

这个会话和它的全部内容都会从所有设备上删掉：

  • 全部消息与附件
  • 已读标记
  • 正在运行的任务会被取消

不可撤销，也无法从回收站恢复。

① 滑动露出的三格P1

第一格（最右、先出）置顶 / 取消置顶（按当前态取反）· 蓝 #3370ff
第二格隐藏 · 中性灰 #646a73
第三格⋯ 更多 · 深灰 #373c43；点开菜单
不放进滑动删除 —— 只走第三格菜单 + 二次确认，避免误触不可撤销操作

「取消隐藏」是体验补全、不是能力补全：上游 hide 顺带取消置顶、pin / set_section 顺带取消隐藏，所以验收只验「入口可达 + 结果与上游一致」。

三档的版面后果（方向改左滑后重算，数值见「行宽余量」）：行左移后露出的是行右端 —— 一档 84px 时头像整块移出、名字左边被切掉约 10px；三档 252px 时时间仍在最右可见，名字/预览只剩尾部约 88px（是尾部，不是开头带省略号）。处理方式不变：行内容不做位移也不淡出、保持原位（iOS 标准行为，重排会让滑动看着抖），滑回即恢复；三档不常驻（点任一格或回弹就收）。 不为 P1 收窄槽宽、也不为版面重排：要「名字从头显示 + 时间常驻」就得重排（例如把名字改到不随行位移的浮层），那是另一个设计，不进本期。
v4 消解：方向改成左滑后，手指是向左走，而系统返回手势是左缘向右拖 —— 两者不再抢，左缘排除区与「加 Capacitor 手势排除插件」都不需要了。右侧没有系统手势；真机上若某 ROM 有右缘手势，再量再定。

③ Hidden 分组P1

  • 位置：置顶 → 各分组 → 未分组 → 隐藏；没有隐藏会话时整组不出现。
  • 组头照分组头样式（12px/650 --muted）+ 数量，默认折叠。
  • 折叠态只存本地：avatar:lorca:hidden-collapsed（同 avatar:lorca:show-tools 口径），不调 sections.collapse —— 上游 Hidden 折叠是每台设备各自的事，写回上游会污染分组折叠。
  • 组内行按最新活动倒序（byActivity）；未读数、运行中状态照常显示；不带置顶角标。
  • 点行照常进详情页（隐藏不等于不可读）。

④ 删除二次确认P1

  • 形态：底部动作面板（复用 .lorca-move 骨架），标题带会话名。
  • 正文说清影响：全部消息与附件、已读标记一并删除；正在运行的任务会被取消。
  • 红色一行写死「不可撤销，也无法从回收站恢复」；主按钮 --danger，取消为安静按钮。
  • 删掉的正是当前打开的详情页 → 回列表并清空选中；列表空了显示空态，不自动打开别的会话。

范围与不做什么

P1① 滑动三格 ② 第三格 ⋯ 菜单 ③ Hidden 组 ④ 白名单扩 chats.hide / chats.mute / chats.delete（各带契约测试）⑤ 删除二次确认
P2静音/取消静音 + 行上静音标记；详情页 ⋯ 补隐藏与静音。静音不是纯 UI：协议 + 归一化要一起动（mute 现在 avatar 一行都没读）
不做会话重命名、会话搜索、长按菜单、分组拖拽、左滑标记已读、行尾常显 ⋯
「列表一滚即关」按 真实滚动量判，不按手指 dy —— 否则已锁定横向的斜滑会因 dy 抖动把行误关。行上需 touch-action: pan-y，WebView 里才既保住原生纵向滚动又收到横向 pointer 事件。

验收口径（可逐条核）

  • AC-1 常态行向左滑：84px 露「置顶」、168px 露「隐藏」、252px 露「⋯」；三格各 84px，露出顺序为 置顶 → 隐藏 → ⋯（最右格先出）；三格都贴在行尾（右）一侧。
  • AC-2 向左滑松手：41px 回 0、100px 停 84px、150px 停 168px、220px 停 252px（四点各测一次）；向右滑不开格。
  • AC-3 向左：dx=-20,|dy|=8 → 横向、行跟手；dx=-20,|dy|=25 → 纵向、交回滚动；dx=-20,|dy|=16 → 未起判区、行不跟手。
  • AC-4 A 行开着时滑 B 行，A 立即回 0，只有一行是开的。
  • AC-5 行开着时列表纵向滚动 > 6px，行关闭；按住不动、scrollTop 不变时不关。
  • AC-6 行开着时点行内正文，只关行、不进详情页；行关着时点正文正常进详情页。
  • AC-7 常态行尾没有 ⋯（与「现状 · 改前」屏逐行对比）。
  • AC-7b 版面（左滑）：一档 84px 时头像整块移出、名字左边被切约 10px；三档 252px 时可见 138px，时间仍在最右可见，名字/预览只剩尾部；名字/预览不发生位移或淡出（除滑动本身）。
  • AC-8 点第三格 ⋯ 开菜单，三项齐全（移到分组 / 标记为已读 / 删除会话）；未读为 0 时「标记为已读」置灰；点外面关；返回键先关菜单。
  • AC-9 隐藏一个会话：它离开原分组、进列表底部「隐藏」组、未读数与运行中状态都在、置顶角标消失。
  • AC-10 Hidden 组默认折叠；展开后杀掉 App 重开仍是展开（本地存）；另一台设备的分组折叠态不受影响。
  • AC-11 取消隐藏后会话回原分组；隐藏组里最后一个取消后，「隐藏」组头消失。
  • AC-12 删除：确认面板文案含「不可撤销」与附件/已读/运行中任务三项；确认后行从列表消失；若删的是当前打开的会话，回到列表且不自动打开别的会话。
  • AC-13 白名单三条各有一条契约测试；白名单外的方法仍然 fail-closed。
  • AC-15 Hidden 行 ⋯ 菜单第一项写作「移到分组（并取消隐藏）」——上游 set_section 会顺带把会话移出 Hidden。
