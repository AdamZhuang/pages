Tab 与页面骨架 AC-1

  • 四档：会话 / 已完成 / 自动化 / 额度，额度排最后（图 ① 是改前的三档，只用来对比）。
  • 「已完成」仍只在真有已完成会话时出现（issue #1 定稿），额度永远出现。
  • 页头一行：左「ClinePass」、右「上次更新 16:20」+「刷新」。进入 Tab 拉一次，之后只靠按钮（不做轮询）。

版面顺序 Adam 2026-10-18

  • 配额卡在最上，余额卡沉到最底下 —— 他说「主要是看订阅配额的」。
  • 配额卡里三档：最近 5 小时 / 最近 7 天 / 本月，各一行百分比 + 进度条 + 重置时间。
  • 主数字写「已用 x%」（进度条填满 = 用完），副行「剩 y% · 10-24 16:57 重置」。
  • ≥80% 转警示色、满 100% 转危险色 —— 撞限流前能看出来。
三档都是上游给的（v3 改口）：官方 GET /api/v1/users/me/plan/usage-limits 一次返回 five_hour / weekly / monthly 三档的 percentUsed 与 resetsAt。 之前「30 天不显示」是因为我自己按记录求和、只覆盖 1.4 天 —— 那个理由现在不成立了，本月放开显示。

一次拿全，不用分档加载 v3

  • v2 的「5 小时先到、7 天补上」作废：一个请求几百毫秒返回三档，分档加载没有意义了。
  • 保留一个整卡加载态（图 ④）：点刷新后卡片显示「正在读取…」+ 骨架，几秒内出结果。
  • 缓存 5 分钟仍保留，但只为省流量，不再是为了掩盖 15 秒的等待。
  • 百分比原样显示上游的整数，不补小数位、不自己四舍五入 —— 不加工精度。

没配 key 时不画卡 AC-2

not_configured 时不渲染两块卡，只有状态条 + 「设置 API key」。两块都必然空，各降级一次就是两行「取不到」，比空态更糊。

原因码与人话 AC-4 / AC-6

码层级主文案下一步
not_configured全局还没设置 Cline API key设置 API key
key_invalid全局这个 key 不被接受替换 key（附：到 Cline 账户页重新复制）
network_unreachable全局连不上 Cline，检查网络后再试重试
upstream_no_data块级Cline 返回了空数据，暂时取不到重试
quota_unavailable块级上游没有提供读取订阅配额的接口可在 Cline 官网账户页查看用量
层级不许串：前三条是全局条，后两条只出现在它自己那张卡里。前端只按码取文案，不许自己拼英文、不许把上游原文或 HTTP 状态码写进界面。
quota_unavailable 现在基本用不上了（接口已找到），但保留 —— 订阅过期 / 无 entitlements 时还会落回它。

两块独立降级 AC-7

  • 配额这块挂了不影响余额块（图 ⑤：两块都空数据，各自说明）。
  • 没有 resetAt 就不渲染「重置时间」这一行，不留空行占位。
  • 余额数值不加货币符号（上游只给 number，单位不知道就不写），小字固定「Cline 账户余额，不是 ClinePass 订阅配额」。
  • 配额卡不再有「与官方口径可能有差异」那句小字（v3）：数字就是上游算的，留着反而是自我怀疑。
  • key_invalid / network_unreachable 时两块保留骨架、内容位写「—」，不重复全局条那句原因。

设置 key：普通文本格子 v2 改口

  • 输入框不要密文、不要眼睛按钮、不要安全键盘，就是普通文本框（type="text"，关掉自动纠正/首字母大写）—— 粘贴优先。
  • 安全性改由「打开弹层永远是空的」保证：已存的 key 永不回显，要换就重新粘一次。
  • 保存成功只回 toast「已设置」；清除走二次确认「清除后将看不到额度」。
  • 保存失败留在弹层、错误行 + 不丢用户刚粘的那串。
  • 自测截图规矩：key_invalid 那态用假 key；有额度那态截之前把弹层关掉，别让真 key 进截图。
